# AgilizaZap — downloads

Instaláveis do AgilizaZap. Aqui não há código-fonte nem dados de loja.

## Agente de impressão (Windows)

**Baixar a versão mais nova:**
https://github.com/fcgamers/agilizazap-downloads/releases/latest/download/agilizazap-print-agent.exe

### Instalar ou atualizar
1. No PC da impressora, baixe o `.exe` pelo link acima.
2. Dê duplo-clique, de qualquer pasta. Na primeira vez ele pede o **código de instalação** gerado no app (Configurações › Impressão). Se já houver um agente instalado, ele é trocado pelo novo.
3. Se o Windows mostrar o aviso do SmartScreen, clique em **Mais informações › Executar assim mesmo** (o `.exe` ainda não tem assinatura digital).
4. **Não** use "Executar como administrador".

As versões anteriores ficam em [Releases](https://github.com/fcgamers/agilizazap-downloads/releases).
